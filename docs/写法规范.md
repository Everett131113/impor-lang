# Impor (I++) 写法规范（4.0.0）

> 版本：v4.0.0
> 定位：面向人和工具的**唯一写法清单**。`docs/语言规范.md` 定义语法；`impor fmt` 决定格式化后的落地写法；本表只列 v4 实际接受的写法。
> 原则：同一意图只给一个写法。12 类历史写法已在 v4.0.0 从 lexer/parser 物理删除，写了会得到 `E2002`。

## 0. 三条硬规则

1. **一种意图，一种写法**。本表「写法」列就是唯一答案；v4 不再把旧写法降级为兼容 AST。
2. **格式化即事实**。`impor fmt` 只输出本表写法；`impor check-fmt` 是全仓门禁。
3. **删除即报错**。已删除的 12 类写法不会静默改义，也不会被 fmt 悄悄修正，而是直接拒绝。

## 1. 已删除的 12 类写法（v4.0.0）

| 已删除 | 唯一写法 |
| --- | --- |
| `func f(a) {}` / `func f a, b` | `def f(a, b) {}` |
| `loop {}` | `while true {}` |
| `let x` / `local x` | `var x` |
| `print "x"` / `print x` / `print a, b`（任意无括号形式） | `print(x)` / `print(a, b)` |
| `x := 1` | `set x = 1`（已声明后 `x = 1`） |
| `x++` / `x--` / `++x` / `--x` | `x += 1` / `x -= 1` |
| `a && b` / `a \|\| b` / `!a` | `a and b` / `a or b` / `not a` |
| `a <> b` | `a != b` |
| `if x then` | `if x:` 或 `if x {}` |
| `unless x` | `if not x` |
| `for each x in xs` / `for x of xs` | `for x in xs` |
| `for i in 1..5` / C 风格 `for` / `do..until` | `for i in range(1, 6)` / `while` |

## 2. 语句与分隔

| 意图 | 写法 | v4 状态 |
| --- | --- | --- |
| 多条语句 | 一行一条 | 推荐 |
| 语句块 | `{ ... }` | 推荐；冒号 + 缩进块仍兼容，但新代码不用 |
| 空语句 | 不写 | 分号仍可分隔，但 fmt 不改写，团队统一一行一条 |

## 3. 输出

| 意图 | 写法 | v4 状态 |
| --- | --- | --- |
| 打印 | `print(a, b)` | 唯一；无括号形式已删除 |
| 带退出码结束 | `exit(2)` | 推荐；裸 `exit` 仍等价 `exit(0)` |

## 4. 变量与常量

| 意图 | 写法 | v4 状态 |
| --- | --- | --- |
| 声明变量 | `var x = 1` | 唯一；`let/local` 已删除 |
| 赋值 | `set x = 1` | 推荐；已声明后 `x = 1` 仍可用 |
| 只读常量 | `const N = 10` | 推荐；`static/readonly` 仍是别名 |
| 类型注解 | `var x: int = 1` | 可选；只查字面量初始化 |
| 省略初始化 | `var x = null` | 推荐；`var x` 仍兼容 |

## 5. 条件

| 意图 | 写法 | v4 状态 |
| --- | --- | --- |
| 条件分支 | `if x > 0 { ... } elif y { ... } else { ... }` | 推荐；`elseif` 仍是别名 |
| 取反条件 | `if not x { ... }` | 唯一；`unless` 已删除 |
| 块引导 | `:` 或 `{}` | `then` 已删除 |

## 6. 循环

| 意图 | 写法 | v4 状态 |
| --- | --- | --- |
| 遍历集合 | `for x in 表 { ... }` | 唯一；`each/of` 已删除 |
| 计数循环 | `for i in range(0, n) { ... }` | 唯一；`1..n` 与 C 风格 `for` 已删除 |
| 条件循环 | `while cond { ... }` | 推荐；`do..until` 已删除 |
| 无限循环 | `while true { ... }` | 唯一；`loop` 已删除 |

## 7. 函数

| 意图 | 写法 | v4 状态 |
| --- | --- | --- |
| 定义 | `def f(a, b) { ... }` | 唯一；`func` 与免括号参数已删除 |
| 返回 | `return x` | 推荐；末行隐式返回仍兼容 |
| 返回类型 | `def f(a) -> int { ... }` | 可选注解，只做编译前检查 |

## 8. 类与对象

| 意图 | 写法 | v4 状态 |
| --- | --- | --- |
| 继承 | `class 子(父) { ... }` | 推荐；`extends` 仍兼容 |
| 实例化 | `new A(x)` | 推荐；`new A` 省空括号仍兼容 |
| 调父类 | `super().m(x)` | 推荐；`super.m(x)` 仍兼容 |

## 9. 异常

| 意图 | 写法 | v4 状态 |
| --- | --- | --- |
| 捕获 | `catch e { ... }` / `catch Type e { ... }` | 推荐；`catch {}` 仍兼容 |
| 抛出 | `raise Err("m")` | 唯一 |
| 异常链 | `raise Err("m") from old` | 唯一 |

## 10. 运算符

| 意图 | 写法 | v4 状态 |
| --- | --- | --- |
| 逻辑与/或/非 | `and` / `or` / `not` | 唯一；`&&` / `\|\|` / `!` 已删除 |
| 不等 | `!=` | 唯一；`<>` 已删除 |
| 自增自减 | `x += 1` / `x -= 1` | 唯一；`++/--` 已删除 |
| 区间 | `range(a, b + 1)` | 唯一；`a..b` 已删除 |

## 11. 中文关键字

**现状：中文关键字已移除。** `如果` / `变量` / `打印` 等只按普通标识符处理；中文**标识符**仍完全可用，例如 `var 总数 = 0`。

## 12. 注释与文档

| 意图 | 写法 | 说明 |
| --- | --- | --- |
| 普通注释 | `# 说明` | 不进符号表、不进 hover |
| 文档注释 | `## 说明`（紧邻声明上方，可多行） | 进符号表、进 LSP hover、进 `impor doc` |
| 多行注释 | `/* ... */` | 仅作说明，不绑定声明 |
| 抑制 lint | `# impor-lint-ignore` / `# impor-lint-ignore-file` | 见语言规范 |

## 13. 模块与导入

| 意图 | 写法 |
| --- | --- |
| 导入模块 | `import math` |
| 部分导入 | `from math import sqrt` |
| 对外导出 | `export def f(...)` / `export var x` |

## 14. 检查方式

```text
impor lint FILE            # 语义检查（未定义/未使用/死代码/参数个数）
impor lint --style FILE    # 额外检查本表 + 可读性提示
impor check-fmt FILE       # 检查是否已格式化
impor doc FILE -o API.md   # 从 ## 文档注释生成 API 文档
```

全仓门禁：

```bash
python tools/check_fmt_all.py
python tools/audit_aliases.py
```

## 15. 后端能力边界（4.0.0）

发布路径只有 C 后端（`impor build`，出 exe 或 `--lib` 出 dll）。解释器只做开发期 `run/repl/run-dbg`；`impor compile` 只做开发兼容。

| 能力 | 解释器 / Python 转译 | C 后端 / imporc |
| --- | --- | --- |
| 类型注解 | 已检查字面量赋值与返回类型 | 仅 Python 转译路径 |
| `yield` / 生成器 | 未实现 | 未实现 |
| 列表/字典推导式 | 未实现 | 未实现 |
| 默认参数 / 变参 | 未实现 | 未实现 |
| `with` | 未实现 | 未实现 |
| `try/catch` | 已支持（含自定义异常） | 仅内建异常子集；自定义异常编译期拒绝（rc=3） |
| 线程 / 原子操作 | 无语言级内建 | 无语言级内建 |
| 导出 `.dll` | 不适用 | 支持顶层 `export def` + 显式 `int/float/bool/str/void/size_t/handle/ptr` |

这张表是 v4.0.0 的交付边界，不是路线图承诺。未实现项不会被文档包装成“已支持”。
