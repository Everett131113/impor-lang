## 第 9 课 · 类与对象

**目标**：定义类、构造函数与方法

**讲解**：class 内用 def __init__ 初始化，self 访问字段，new 创建实例。

### 练习

```impor
class Counter
    def __init__()
        set self.n = 0
# TODO: 增加 add 方法并输出 count
```

### 参考答案

```impor
class Counter
    def __init__()
        set self.n = 0
    def add(x)
        set self.n = self.n + x
    def value()
        return self.n

var c = new Counter()
c.add(3)
c.add(4)
print("计数:", c.value())
```

### 期望输出

```text
计数: 7
```

## 第 10 课 · 枚举与匹配

**目标**：enum + match 的穷尽分支

**讲解**：enum 定义常量；match 按分支执行；没有 else 时类型检查会要求覆盖全部成员。

### 练习

```impor
enum Color { RED, GREEN, BLUE }
var c = Color.GREEN
# TODO: 用 match 输出 红/绿/蓝
```

### 参考答案

```impor
enum Color { RED, GREEN, BLUE }
var c = Color.GREEN
match c
    case Color.RED:
        print("红")
    case Color.GREEN:
        print("绿")
    case Color.BLUE:
        print("蓝")
```

### 期望输出

```text
绿
```

## 第 11 课 · 异常处理

**目标**：抛出与捕获自定义异常

**讲解**：exception 定义异常，raise 抛出，try / catch / finally 捕获与收尾。

### 练习

```impor
exception ScoreError
# TODO: 抛出并捕获，输出 捕获异常
```

### 参考答案

```impor
exception ScoreError
func check(score)
    if score > 100
        raise ScoreError("非法成绩")
    return score

try
    check(120)
catch ScoreError e
    print("捕获异常:", e.msg)
finally
    print("检查结束")
```

### 期望输出

```text
捕获异常: 非法成绩
检查结束
```

## 第 12 课 · 闭包与高阶函数

**目标**：返回函数并在调用之间保留状态

**讲解**：外层函数的局部变量会被内层函数捕获；make_counter 每次调用都保留自己的计数。

### 练习

```impor
func make_counter()
    var n = 0
    # TODO: 返回一个每次 +1 的函数
```

### 参考答案

```impor
func make_counter()
    var n = 0
    func next()
        set n = n + 1
        return n
    return next

var c = make_counter()
print(c())
print(c())
```

### 期望输出

```text
1
2
```
