# Impor Code Studio 3.0

> 版本：3.0.0 · 2026-11-12

本版编辑器在 7.2 的渐进式启动、自动更新、项目设置、只读插件 API、Git、终端、智能提示与可访问性之上，补齐「项目级质量入口、教学入口、插件写权限」，并继续复用已有的项目索引、符号跳转、调用层级、重命名、提取函数、DAP、测试浏览器、多光标、折叠与 diff。

## 项目质量检查

命令面板执行「项目质量检查（类型+lint）」：

- 遍历工作区 `.impor` 文件，排除 `.git`、`.impor_recovery`、`build`、`dist`、`node_modules`、`__pycache__`、`.impor`。
- 每个文件先跑 `analyze`，再跑 `typecheck.check_source`。
- 诊断进入「问题」面板，消息带错误码（如 `type-mismatch`、`match-exhaustive`、`access-private`），最多显示 300 条。
- 同步更新状态栏错误/警告计数，并自动切到底部「问题」。

单文件保存时也会把类型诊断并入 `_lint_pane`，因此打开文件即可看到可选类型、返回类型、枚举穷尽性与同文件访问控制问题。

## 教学入口

- 命令面板「教学大纲（12 课）」打开 `docs/教学大纲.md`。
- 命令行 `impor teach` 列出 12 课；`impor teach 3` 显示讲义与练习；`impor teach 3 --exercise/--answer/--write` 写出文件；`impor teach grade 3 FILE` 自动判题。
- 练习、答案与教师讲义见 `docs/教学练习.md`、`docs/教师讲义.md`。

## 插件写权限

插件 API 在 7.2 的只读能力基础上新增：

- `write_file(path, content)`：写入工作区内文件。
- `write_current(content)`：替换当前编辑器已保存文件内容。

默认拒绝。授权方式二选一：

```json
{
  "plugin_write_allow": ["demo.py", "*"]
}
```

或环境变量：

```bat
set IMPOR_PLUGIN_PERMISSIONS=write
```

约束：

- 未授权抛 `PermissionError`，错误消息说明如何授权。
- 写入路径必须位于工作区内，`commonpath` 校验，阻止插件改系统文件。
- 写入使用 UTF-8、`\n` 换行。
- 插件仍与编辑器同进程，只加载 `.impor/plugins` 与 `~/.impor_studio/plugins` 下用户明确放置的脚本；独立进程隔离未实现。

## 已有能力（7.2 起）

- 项目索引：`ProjectIndex` 增量按 mtime 更新，支持定义、引用、重命名编辑。
- 符号跳转、调用层级、重命名、快速修复、提取变量/函数。
- DAP 调试 UI、断点、条件断点、日志点、单步。
- 测试浏览器、统一 diff、多光标、代码折叠。
- 全项目搜索（Ctrl+Shift+F）、问题面板、命令面板、终端与任务模板。
- 高对比主题、Ctrl+1..5 区域跳转、字号缩放、大文件可视行着色。

## 验证方式

```bat
impor check examples\demo_01_variables.impor
impor teach
impor teach grade 1 lesson01_answer.impor
```

编辑器窗口标题应为 `Impor (I++) 3.0.0 · Code Studio`。本项目没有自动化 GUI 测试，窗口级验证需人工打开确认。
