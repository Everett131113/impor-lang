# 4.8.0 同步说明

## 这次装了什么

安装目录仍是 `Impor 4.0.0`（名字从 4.0 起就被桌面快捷方式、`impor.bat`、`.lnk` 硬绑，改名会断掉这些入口，所以不改）。里面的代码是 4.8.0。

| 包 | 值 |
|----|----|
| 发布包 | `Impor-4.8.0-Windows-x64.zip` |
| 条目数 / SHA256 | 以 `python tools\pack_release.py` 的打印为准（本文档随包发布，改数字会让包内容变化，故不写死） |
| VERSION | 4.8.0 |

## 这次带来的变化

1. **性能门禁**：`python tools\bench_gate.py --check`，四基准 × 两口径，超基线 30% 或输出不符即退出 1。
2. **两级编译**：`impor run` 首次 1.46 s → 1.056 s，后台自动升级到满档，第二次 0.511 s。
3. **第二后端 WASM**：`impor wasm x.impor -o x.wasm [--html x.html]`，浏览器/Node 直接跑，子集外编译期拒绝。
4. **能力矩阵门禁**：`python tools\capability_gate.py --check`，十探针 × 三后端，`docs\CAPABILITIES.md` 自动生成。

细节见包内 `docs\Impor 4.8.0 发布说明.md` 与 `docs\第二个后端-WASM-4.8.0.md`。
