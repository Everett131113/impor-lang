# Impor (I++) 新手教程

> 版本：v2.6+（与 v2.6.0 实现完全一致，文中所有示例均已在解释器实测通过）
> 建议时长：30~45 分钟。读完你就能用 Impor 写小游戏、命令行工具和小型脚本。

---

## 1. Impor 是什么？

Impor（读作 **I++**）是一门**缩进即代码块**的脚本语言，语法像 Python 一样简洁，
又内置了游戏开发常用工具（向量、随机、Tk 图形界面）。它的特点：

- **零依赖上手**：一个 `Impor.py` 启动器 + 一套 impor 包即可运行；
- **双后端**：默认用树遍历解释器直接跑（教学友好），也可 `compile` 转译成 Python；
- **中文/英文混写**：变量名、函数名可以用中文；
- **游戏友好**：`vec2`、`rgb`、`clamp`、`lerp`、`randi` 等开箱即用。

```python
print("你好，Impor!")
```

## 2. 安装与运行

把项目目录放到任意位置，无需 pip 安装即可使用：

```
# Windows 命令行
python Impor.py run 脚本.impor
# 或安装为全局命令（可选）
pip install -e .
impor run 脚本.impor
```

三个最常用的命令：

| 命令 | 作用 |
|---|---|
| `python Impor.py run 文件.impor` | 运行脚本 |
| `python Impor.py repl` | 交互式解释器（一行一行试） |
| `python Impor.py new 名字.impor` | 生成新脚本模板 |

## 3. 第一个程序

新建 `hello.impor`，写入：

```python
print("你好，Impor!")
var 名字 = "小明"
print("欢迎，", 名字)
```

运行：

```
python Impor.py run hello.impor
```

输出：

```
你好，Impor!
欢迎， 小明
```

> 提示：`print` 可以一次打印多个值，用空格分隔。

## 4. 变量与类型

用 `var` 声明变量，用 `set` 修改变量：

```python
var 年龄 = 17              // 整数
var 分数 = 92.5            // 小数
var 名字 = "小明"           // 字符串
var 是否及格 = true         // 布尔 true / false
var 空值 = none            // 空值

set 分数 = 分数 + 7.5       // 修改
print(分数)
```

支持的复合赋值（`+= -= *= /= %=`）直接写在变量上：

```python
var x = 10
x += 5      // x = 15
x -= 3      // x = 12
x *= 2      // x = 24
x /= 4      // x = 6
print(x)
```

类型可以随时改变（动态类型）：

```python
var v = 1
set v = "现在我是字符串了"
print(v)
```

## 5. 运算符

| 类别 | 运算符 |
|---|---|
| 算术 | `+  -  *  /  %`（`/` 得小数；整除可配合 `math.floor`） |
| 比较 | `==  !=  <  >  <=  >=` |
| 逻辑 | `and  or  not` |
| 三元 | `条件 ? 真值 : 假值` |

```python
var a = 10
var b = 3
print(a + b, a - b, a * b, a / b, a % b)   // 13 7 30 3.3333... 1
print(a == b, a != b, a > b)               // false true true
print(a > 5 and b < 10)                    // true
print(a > 5 ? "大" : "小")                 // 三元：大
```

## 8. 流程控制

### if / elseif / else

```python
var score = 85
if score >= 90
    print("优秀")
elseif score >= 60
    print("及格")
else
    print("不及格")
```

### while / for

```python
var i = 0
var s = 0
while i < 5
    set s = s + i
    set i = i + 1
print(s)            // 10

for i in range(0, 5)     // range(起点, 终点)，不包含终点
    set s = s + i

while true               // 无限循环（用 break 退出）
    print("hi")
    break
```

`break` 跳出循环，`continue` 跳过本次迭代：

```python
var i = 0
while i < 10
    set i = i + 1
    if i == 3
        continue          // 跳过 3
    if i == 6
        break             // 到 6 停止
    print(i)              // 输出 1 2 4 5
```

### match-case 模式匹配

```python
var 颜色 = "红"
match 颜色
    case "红":
        print("红色")
    case "绿":
        print("绿色")
    default:              // 或 else:，兜底分支
        print("其它")
```

## 10. 类与继承

注意：**方法定义时不用写 `self` 参数**，方法内部用 `self` 访问实例。

```python
class Animal
    def __init__(名字)
        set self.名字 = 名字
    def 叫()
        print(self.名字, "在叫")

class Dog(Animal)          // 继承
    def 叫()
        super().叫()       // 调用父类方法
        print(self.名字, "汪汪叫")

var d = new Dog("旺财")
d.叫()                     // 旺财 在叫 / 旺财 汪汪叫
```

类字段直接在类体内声明，实例自动拥有：

```python
class 点
    var x = 0
    var y = 0

var p = new 点()
set p.x = 5
set p.y = 7
print(p.x + p.y)          // 12
```

如果这个类型**只有字段、没有方法**，用 `struct` 更省事：不用写 `__init__`，构造时按字段顺序直接传值。

```python
struct 点
    var x = 0
    var y = 0

var p = new 点(5, 7)
print(p.x + p.y)          // 12
set p.x = 10              // 字段可读写
```

`struct` 体内只能写 `var 字段名 = 默认值`；需要方法时改用 `class`。

## 11. 异常处理

```python
try
    var a = to_num("不是数字")   // 转数字失败返回 0，不会报错
    print(a * 2)
catch err                          // 捕获任意异常
    print("出错啦:", err.msg)
finally
    print("总会执行")
```

自定义异常并用类型捕获：

```python
exception 年龄错误                      // 声明一种新异常

def 检查(n)
    if n < 0
        raise 年龄错误("年龄不能为负")
    return n

try
    检查(-1)
catch 年龄错误 e                        // 按类型捕获
    print("捕获:", e.msg)
```

异常对象有 `.msg` 字段保存消息；`catch` 支持三种写法：
`catch err`（任意）、`catch 类型 err`、`catch 类型, e`。

## 12. 模块与代码组织

```python
def add(a, b)
    return a + b

```

## 15. 内存管理（自动回收，v3.2）

Impor 的对象内存自动管理，不需要手动申请或释放：

- 每创建一个数组、字典、类实例，解释器记一次分配；
- 累计分配达到阈值（默认 20000 个对象）自动回收一轮；
- 也可以随时查看内存、手动触发回收：

```python
print(mem())        // 打印当前内存摘要
print(memstats())   // {alloc, peak, live, collections, threshold, auto, ...}
print(gc())         // 立即回收一轮，返回本轮清理的对象数
autogc(500)         // 把自动回收阈值改成 500（0 = 关闭自动回收）
```

看一个分配与回收的例子：

```python
var 列表 = []
for i in range(0, 1000)
    set 列表 = arrappend(列表, i)
print(mem())
print("累计回收次数:", memstats()["collections"])
print("本轮清理对象:", gc())
```

命令行也可以直接看：

```powershell
python Impor.py mem            # 进程内存 + 存活分类 + 阈值 + 内建清单
python Impor.py mem 脚本.impor # 运行脚本，对比「运行前存活 → 运行后存活」
```

C 后端（`impor build` 生成独立 exe）同样支持 `mem()` / `gc()`：数组分配登记在托管表、字符串字面量进入驻留池（同一字面量只分配一次），`gc()` 会释放托管数组并打印分配/字节/峰值计数。

## 15.1 跨后端注意事项（v3.3）

同一份代码可能跑在三条路径上：`impor run`（解释器）、`impor build`（C 后端 + tcc）、`imporc.exe`（自举编译器）。v3.3 把这些地方对齐了，写代码时记住：

```python
print(len("你好"))        # 2 —— 按字符计数，不是字节
print("你好"[1])          # 好 —— 下标 0 起，负数从末尾算
print(strcut("你好世界", 1, 3))   # 好世

print(1 == true)         # true —— 布尔当作 0/1 参与比较
print("ab" * 3)          # ababab —— 字符串 × 整数重复

print(1 + "a")           # 报 TypeError：改成 to_str(1) + "a" 才拼接
```

- **整数范围**：C 后端是 64 位有符号整数，超出会直接报 `整数溢出：超出 64 位有符号整数范围`；解释器是 Python 大整数。跨后端程序请把数值控制在 ±9.2e18 内。
- **递归深度**：解释器约 3000 层，超了报 `RecursionDeep`（不是 Python 的 `RecursionError`）。阶乘/斐波那契这类递归没问题，深递归请改循环。
- **C 编译报错**：`impor build` 失败时会给出 `C 编译错误: 第N行 列M` + 源码行 + 指示符，已经映射回 Impor 源码位置，不再是一串 tcc 英文。
- **一致性自测**：`python conformance/run_conformance.py` 会用 20 个脚本把三条路径各跑一遍并逐字节比对，改动语言后先跑它。
- **imporc 参数**：参数写在 `imporc_args.txt`，按空格切分，路径含空格时必须加双引号：`build "D:\My Dir\a.impor" -o "D:\My Dir\out.exe"`。

## 15.2 一个意思，一种写法（v4.0.0）

v4.0.0 起，历史兼容写法已从 lexer/parser 物理删除；再写会直接报 `E2002`，不再“宽容解析”。

```impor
# 打印：必须带括号
print("hi")
print(a, b)

# 语句分隔：换行或分号
var a = 1
var b = 2; var c = 3

# 类型注解
var count: int = 0
def add(a: int, b: int) -> int { return a + b }

# 条件：冒号或大括号块
if x > 0: print("正")
elif x == 0: print("零")
else: print("负")

# 循环
for i in range(1, 6) { print(i) }   # 1,2,3,4,5
for x in 表 { print(x) }
while n < 3 { set n = n + 1 }

# 自增自减、逻辑运算
n = n + 1
arr[0] = arr[0] - 1
if a and b or c { print("ok") }
if a != b { print("不等") }
```

**已删除的写法**：`func`、`loop`、`let/local`、裸 `print`、`:=`、`++/--`、`&& || !`、`<>`、`then`、`unless`、`for each/of`、`1..n`、C 风格 `for`、`do..until`。旧代码请按上面的唯一写法改写。

## 16. 综合练习：猜数字

```python
while 低 <= 高                // 二分查找

    if 结果 == "猜中"

        break
    elseif 结果 == "太小"
        set 低 = 中 + 1
    else
        set 高 = 中 - 1
```

## 15.3 文档注释：让说明跟着代码走（v3.5）

`#` 是写给自己的普通注释；`##` 是**文档注释**，会跟着符号走——编辑器悬停能看到，`impor doc` 能直接生成文档。

```impor
## 计算两数之和
## 返回 a + b
def add(a, b) {
    return a + b
}

## 温度盒子
class Box {
    ## 构造：保存一个值
    def __init__(v) {
        self.v = v
    }

    ## 取出内部的值
    def get() {
        return self.v
    }
}

print(add(2, 3))
var b = new Box(9)
print(b.get())
```

```text
python Impor.py doc 文档示例.impor -o API.md
```

规则很简单：`##` 要占满整行（行首可以缩进），连续几行会合并成一段，只绑定紧随其后的第一条声明。

另外，v3.5 起有了唯一「推荐写法表」（`docs/写法规范.md`）：新代码按推荐写法写，旧写法仍然能跑。想检查自己的工程里有没有兼容写法：

```text
python Impor.py lint --style 你的文件.impor
```

## 16. 看懂报错：四段式诊断（v3.6）

从 v3.6 起，每条报错都按同一结构回答四件事：**哪里、是什么、为什么、怎么修**。

```text
impor: 语法错误: 第1行 列9: 表达式缺失  · demo.impor
  1 │ var x =
    │          ^
  2 │ print(x)
  为什么： 该位置需要一个值或表达式，但语句在这里提前结束了。
  修复： 在 =、return、(、[ 之后补上变量、字面量或表达式；也可以先只声明变量，再单独赋值。
```

换成运行错误也一样：

```text
impor: 运行错误: 第2行 列10: NameError: 变量 total 未定义  · demo.impor
  1 │ var a = 1
  2 │ print(total)
    │       ^^^^^
  为什么： Impor 不做隐式全局：名字必须先用 var / const / def / import 声明，之后才能使用。
  修复： 先用 var x = ... 声明，或用 import 引入；同时检查拼写与大小写是否一致。
```

读报错的顺序建议：

1. 先看首行的 **行号 列号**，再到代码里定位；
2. 看 **是什么**：`语法错误` 说明还没开始执行，`运行错误` 说明执行到这一行才出问题；
3. 看 **为什么**：理解规则比记住一条建议更有用；
4. 最后照 **修复** 改，通常一两步就能跑通。

两个实用开关：

```text
set IMPOR_COLOR=never          # 关掉颜色（默认只在终端里上色）
set IMPOR_DEBUG=1              # 运行错误时打印完整调试栈
```
