# Impor v6.0 路线图（四条线）

> **历史内部文档，不是发布版本。** 当前对外发布为 `3.6.6`；本文的 `v6.0` 只是早期路线编号，部分条目已并入 3.6.x。安装包请以 `VERSION` / `docs/版本对齐与语法冻结-3.6.6.md` 为准。

> 定位：中文母语入门 + Windows 小工具独立 exe。v6.0 的目标不是“功能更多”，而是“说过支持的东西真的成立”。

## 1. 诚信：冻结语法，三端同语义

| 项目 | 状态 | 说明 |
|---|---|---|
| `implements` 契约校验 | 已完成 | 缺方法直接 `ContractError`（E1014），基类方法算实现 |
| `ContractError` 诊断 | 已完成 | 新增错误码、中文“为什么/修复” |
| 修饰符访问控制 | 进行中 | 目前仅声明性标记；下一步做 `private/protected` 真检查或从关键字表删除 |
| JSON / 正则 C 后端 | 计划 | 解释器已支持，C 后端/自举未同步，build 前会显式报错 |
| `lambda` C 后端 | 计划 | 当前 `impor build` 明确拒绝，不静默降级 |

## 2. 性能：只追小工具体感

| 项目 | 状态 | 说明 |
|---|---|---|
| 基准可复现 | 已完成 | `benchmarks/bench_compare.py` + `latest.md` |
| 性能门槛 | 已完成 | `impor bench --gate`，v6.1 收紧到 3400 ms；v6.2 实测 520–563 ms |
| 热路径优化 | 已完成 | v6.1 帧采样降频、const 检查短路、整数热路径、当前作用域直查；v6.2 函数调用帧预计算与成功路径去 `sys.exc_info` |
| 启动导入 | 已完成 | v6.2 解耦包缓存目录，`run` 不再导入 `pkgmgr` / `urllib` / `ssl` / `zipfile` |
| 字节码 VM / 局部变量槽 | 计划 | 当前 1 秒内已达成小工具体感，VM 降级为后续选项 |
| 发布约束 | 计划 | exe <150 KB、冷启动 <50 ms、不装 Python，每次发布检查 |

## 3. 功能：只做目标人群每天用的

| 项目 | 状态 | 说明 |
|---|---|---|
| JSON / 正则 | 部分完成 | 解释器可用；C 后端待同步 |
| 文件 / 目录 API | 已完成（解释器） | 新增 `filelist` / `filemkdir` / `fileexists` / `filesize`；C 后端/自举待同步 |
| HTTP / 进程 / 压缩 | 计划 | 小工具常用，但必须先定三端策略 |
| GUI 表单/表格/托盘 | 计划 | 面向 Windows 小工具，不做通用 GUI 框架 |
| 包管理依赖解析 | 计划 | 现有本地包/私有源，缺依赖图与离线包 |
| FFI | 计划 | 只做 Windows DLL，不做通用 C 互操作 |

## 4. 人群：把教学体验做成产品

| 项目 | 状态 | 说明 |
|---|---|---|
| 12 课大纲 | 已完成 | `docs/教学大纲.md` |
| `impor teach` 入口 | 已完成 | 终端直接查看大纲，支持 `impor teach 3` |
| 练习 / 答案 / 教师讲义 | 计划 | 大纲只有课程名，缺可交付练习 |
| 在线 Playground | 计划 | 无后端时用单页本地运行版 |
| 作品墙 | 计划 | 10 个可双击 exe，比关键字数量更有说服力 |
| VSIX 上架 | 阻塞 | 缺有发布权限的 PAT；本地 VSIX 已可安装 |

## v6.0 验收命令

```powershell
python Impor.py version
python Impor.py doctor
python Impor.py teach 3
python Impor.py bench --gate
python -m unittest tests.test_v37.TestEnglishKeywords tests.test_v43.TestKeywordCountUnchanged
```

契约校验样例：`class Bad implements Shape { func other() { return 1 } }` 必须报 E1014。
