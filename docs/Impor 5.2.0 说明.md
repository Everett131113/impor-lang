# Impor 5.2.0 说明：科学计数法 + 17 个新内建

## 一、科学计数法

数字字面量支持指数写法：

```
1e3        1000.0
2.5E-4     0.00025
1_000e+2   100000.0
3.0e0      3.0
```

规则：`e` 后必须有数字（可带正负号），否则 `e` 不被当作指数；`1..5` 区间写法保持不变。

## 二、新内建（17 个）

| 分组 | 名字 | 用途 |
|---|---|---|
| 字符串 | strsplit | 按分隔符切串，无分隔符按空白切 |
|  | strcount | 子串出现次数 |
|  | strstart / strend | 开头/结尾判断 |
| 数组 | arrinsert | 指定位置插入 |
|  | arrremove | 删除首个匹配（不存在报错） |
|  | arrsort | 排序，可降序 |
|  | arrcount | 等于某值的个数 |
| 数值 | round | 四舍六入五成双，可带位数 |
|  | floor / ceil | 向下/向上取整 |
| 逻辑 | any / all | 任一/全部为真 |
| 函数式 | map / filter | 逐元素调用/筛选 |
| 组合 | zip / enumerate | 按位置组合 / 带下标 |

数组类操作一律返回新数组，不改原数组。
