# Impor 5.1.0 说明：独立输出窗口与控制台运行

## 解决的问题

5.1.0 之前，运行代码的输出只能在编辑器底部的小面板里看，没有像 Python 那样独立的输出界面。
本版本新增两个入口，都在底部「输出」面板的头部右侧。

## 功能一：独立窗口

点击「独立窗口」：

- 弹出一个单独的输出窗口，打开时已有的全部输出和颜色会完整复制过去
- 之后新的运行输出在两个窗口实时同步
- 点「清空」时，底部面板和独立窗口一起清空
- 关闭独立窗口后再点「独立窗口」会重新弹出；窗口已存在时重复点击只会把它提到最前

## 功能二：控制台运行

点击「控制台」：

- 系统弹出一个真正的控制台窗口（独立于编辑器的黑窗口），在里面运行当前代码
- 运行结束后窗口不会立刻消失，提示按任意键关闭，方便回看输出和报错
- 实现方式：把当前代码写到临时文件，生成一个批处理并用新控制台启动

## 验证结果

- 无头探针：历史复制、颜色标记、实时同步、清空联动、窗口复用、控制台批处理生成 全部通过
- 回归合集：40/40 OK（含编辑器无头套件），格式 241/241
- 语言基线：55 关键字 / 124 内建 / 37 模块 / 30 错误码，零改动、无新增语法糖

## 边界

- 控制台运行的是当前编辑区内容的临时副本，不影响已保存的文件
- 控制台窗口使用系统 cmd，中文输出已切换到 UTF-8 代码页
