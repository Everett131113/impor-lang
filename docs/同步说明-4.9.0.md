# 同步说明 4.9.0（桌面）

## 1. 桌面上的东西变了什么

| 位置 | 变化 |
| --- | --- |
| `总Impor文件\关于Impor\Impor 4.9.0\` | **新安装目录**（由 `Impor 4.0.0` 改名而来，868 文件已就位） |
| `总Impor文件\关于Impor\Impor-4.9.0-Windows-x64.zip` | 4.9.0 发布包（868 文件 / 34,427,273 字节） |
| `总Impor文件\关于Impor\vscode-impor-4.9.0.vsix` | 4.9.0 扩展（21,015 字节） |
| `桌面\Impor 编辑器.lnk` | 目标已改指 `Impor 4.9.0\Impor.py`；**图标**（IconLocation）已改指 `Impor 4.9.0\ImporPortable.exe,0`；描述改为 `Impor (I++) 4.9.0 编辑器` |
| 历史备份目录（`Impor 4.0.0 (4.7.x 备份-*)`） | **未动**，保持原名 |

## 3. 怎么确认装对了

```powershell
cd "C:\Users\41482\Desktop\总Impor文件\关于Impor\Impor 4.9.0"
python Impor.py --version        # 应打印 Impor (I++) 4.9.0
python tools\wasm_batch.py       # 12 个 WASM 用例，应输出 TOTAL ok=12 fail=0
```

双击桌面 `Impor 编辑器.lnk` 打开的就是这个目录（`.lnk` 的目标/参数/工作目录/**图标**四处都已改）。

> 4.9.0 改名时踩过一次：只改了前三个字段，`IconLocation` 还指着已删除的 `Impor 4.0.0\ImporPortable.exe,0`，桌面图标变成白纸。
> 现在 `tools\install490.py` 的 `fix_shortcut()` 会在每次安装末尾连带修图标与描述，重装不会回退。图标缓存可用 `ie4uinit.exe -show` 刷新。

## 4. 回滚

想要退回 4.8.0：把 `Impor 4.9.0` 目录改名回 `Impor 4.0.0`，并把 `.lnk` 的参数/工作目录/图标改回，再解压 `Impor-4.8.0-Windows-x64.zip`。
4.8.0 的包与 sha256 都还在桌面 `关于Impor\` 目录里，没有被删。
