# Impor 语法查询

“语法查询”用来回答一个关键字或内建函数怎么用。每条结果固定包含四块：

1. **意思**：它做什么。
2. **格式**：标准写法。
3. **例子**：可以直接抄的最小程序。
4. **例子说明**：逐行解释输出是什么、为什么。

## 三个入口

### 命令行

```powershell
impor syntax print
impor syntax if
impor syntax --search 条件
impor syntax --json print
impor syntax
```

不带参数时列出全部条目；`--search` 按名字、意思、格式、例子做模糊查找；`--json` 给编辑器或脚本消费。

### 编辑器

- 按 `F1`，或命令面板搜索“语法查询”。
- 左侧是关键字/内建函数列表，右侧显示四块内容。
- 输入框可搜名字、意思、例子；选中条目后可“复制例子”。

### REPL

```text
help(print)
help(if)
```

`help(名字)` 现在会优先显示完整语法条目，不再只给一行内建说明。

## print 的查询结果

```text
print（内建函数）

意思
打印：把括号里的内容输出到屏幕，末尾换行。

格式
print("xxx")  /  print(变量)

例子
var a = 1
print("1")
print(a)
print("a")

例子说明
`print("1")` 括号里是字符串 1，输出 1；
`print(a)` 括号里是变量 a，输出 a 保存的值 1；
`print("a")` 括号里是字符串 a，输出 a。
引号只表示字符串，不会把引号一起输出。
```

实际运行结果：

```text
1
1
a
```

## 覆盖范围

- `impor/lexer.py` 的 `KEYWORDS` 全部 73 个保留字，一个不漏。
- 软关键字：`match`、`enum`、`struct`、`unless`、`fn`、`repeat`。
- 常用内建函数：`print`、`input`、`len`、`range`、`type`、`str`、`int`、文件、JSON、正则、内存、FFI 等。
- 预留关键字（如 `with`、`yield`、`defer`、`macro`、`template`）会明确标成“预留，当前无语法”，不给假例子。

## 数据位置

- 查询数据：`impor/syntax_ref.py`
- 命令行：`impor syntax`
- 编辑器入口：`impor/editor.py` 的 `open_syntax_reference`
- REPL：`impor/repl.py` 的 `help(名字)`

新增关键字时，在 `syntax_ref.py` 里补一条；漏补的会在导入时自动归为“预留”，不会出现“查不到”的空条目。
