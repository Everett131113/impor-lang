# v6.3 性能报告：计数循环进入原生数值快路径

> **历史内部性能报告标签，不是发布版本号。** 当前对外发布为 `4.0.0`；本文的 `v6.3` 只用于性能对照。

- 日期：2026-11-21
- 环境：Windows x64 / Python 3.11.5 / gcc 不在 PATH 时用内置 tcc / 本机
- 目标：`for 变量 in range(N)` 这类最常见的计数循环此前完全进不了数值快路径，被静默回退到完整 `Val` 后端（约 6 倍差距）。本轮把 `For` 补进 `cfast`。

## 结果

脚本：`fib(25)` 递归（`cmp_fib25.impor`），`100 万次累加`（`cmp_loop1m.impor`，`for i in range(1000000)`）。
方法：PowerShell 直接起进程、每种跑 5 次取最优、**含进程启动**（不含 shell 包装；用 `cmd /c` 包一层会多约 40 ms，那是 shell 的启动，不是产物的）。

| 路径 | `fib(25)` | 100 万循环 | 后端 |
|---|---:|---:|---|
| 解释器 `impor run` | 287 ms | 2139 ms | 树遍历 + Python 大整数 |
| 构建产物（本机 tcc，默认 `impor build`） | **24.8 ms** | **34.0 ms** | 数值快路径（`long long`，不装箱） |
| 上一轮（`For` 未进快路径时） | 32.6 ms | **214.4 ms** | fib 本来就在快路径；loop 掉进 `Val` 模型 |

> 两轮独立测量的区间：`fib(25)` 24.8–32.6 ms、百万循环 34.0–36.2 ms（5 次与 7 次取最优各一轮，机器负载不同）；上表取较好的一轮。

产物体积：`fib25` 37.5 KB / `loop1m` 37.5 KB（两个都是纯整数脚本，走同一模板）。

## 改了什么

`impor/cfast.py` 五处，都是“补一个原本不认识的语句”，不动既有语义：

1. `_collect_assigns`：`For` 循环变量计入本层变量，并递归收集循环体赋值。
2. `_check_nested_defs`：`For` 体参与嵌套 `def`/`class` 拒绝检查。
3. `_validate_stmt`：新增 `For` 分支——只接受 `for 变量 in range(N)`、`N` 为整数表达式；`range` 多参数或浮点一律 `FastUnsupported`，由 CLI 回退完整后端（不静默改语义）。
4. `_stmt`：生成 C 的 `for`，并把 `range(N)` 的界**先绑到 `long long _n`**，保证“进循环时求值一次”，与解释器一致（循环体改 `n` 不影响迭代次数）。
5. 循环体内 `break` / `continue` 沿用既有 `loop_depth` 计数，无需改动。

## 边界（没有假装的地方）

- 只支持 `range(N)` 单参数；`range(a, b)`、`range(a, b, step)` 仍回退完整后端（下一轮再开口子）。
- 快路径仍是 `long long`，溢出会报中文错误并以退出码 3 结束，要任意精度请 `--no-fast`。
- `for` 循环变量若在循环体内被重新赋值，语义按 C 的“赋值后再自增”执行；解释器侧同一写法也应避免（本轮未对此单独设限，属已知边界）。
- 解释器路径数字没变（287 / 2139 ms）：本轮只动构建后端，不动执行模型。

## 回归

- `tests/test_v41_cfast_for.py`（新增，6 项）：能编、输出与解释器逐行一致、`range(N)` 只求值一次（`n` 被循环体改大仍只跑 3 次）、`range(1,5)` 与 `range(2.5)` 明确回退、`break` 语义一致。
- `tests/test_v41_nonlocal.py`（既有，5 项）仍全绿。
- `tools/check_fmt_all.py` 207/207；`tools/verify_claims.py` 22/22。

## 复现

```powershell
# 构建（默认就走数值快路径）
python Impor.py build cmp_fib25.impor  -o fib25.exe
python Impor.py build cmp_loop1m.impor -o loop1m.exe

# 计时（5 次取最优，含进程启动）
1..5 | % { Measure-Command { .\fib25.exe } | Select-Object -ExpandProperty TotalMilliseconds }
```

> 计时注意：用 `cmd /c` 或 `Start-Process` 包一层会把 shell 自身的启动算进结果（本机约 40 ms），两组数字不可直接对比。
