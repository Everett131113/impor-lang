# Impor 编辑器 3.2.1：安全重构、测试闭环、分块编辑、插件与 UIA

本版编辑器六项升级都已接入主界面，不是独立演示窗口。

## 1. 全项目安全重构

四个入口，统一“先预览 diff、再写入、可一键撤销”：

- 重命名符号：`rename_symbol()` → `_show_rename_preview()`；符号索引给出跨文件改动，预览后 `_apply_rename()`。
- 提取变量 / 提取函数：计算完整 `after` 文本，走 `_preview_text_change()`；绿色 `+`、红色 `-`，点「应用修改」才写入。
- 移动 / 重命名文件：`move_project_file()` 选择目标路径，校验必须在工作区内且不冲突；正则改写所有 `.impor` 的 `from|import <旧模块>`，聚合 diff 预览；应用时先备份，再写引用、`os.rename`，失败回滚。
- 撤销：`undo_refactor()` 恢复文件内容，并按 `moves` 把移动过的文件移回原位。

边界：移动文件只改 `from|import <stem>`，字符串里的路径、包重定向、动态导入不在自动改写范围。

## 2. 测试与调试一体化

- 测试失败内联：解析 `file.impor:行` 或“第 N 行”，对已打开 pane 加 `test_fail` 红字下划线，行号栏画 `✖`；错误明细显示在底部。
- 只重跑失败：`rerun_failed_tests()` 复用失败集合，不跑全量。
- 覆盖率视图：`show_coverage()` 扫描工作区非测试 `.impor` 的 `func`（跳过 `main`），按测试文件中的调用/引用计算覆盖率；Treeview 列出状态/函数/文件/行，双击跳转。注意这是静态调用近似，不是运行时行覆盖。
- 断点持久化：`breakpoints` 随会话保存/恢复，`toggle_breakpoint()` 与行号栏同步。

## 3. 大文件分块可编辑

`VirtualLargeFilePane` 从“只读浏览”升级为“可编辑窗口”：

- 完整行列表留在内存，Tk Text 只装当前窗口（默认 3,000 行）；窗口内 `state=normal`、`undo=True`。
- 编辑后 450ms 防抖 `flush_virtual()` 回写完整行列表；换块前强制回写。
- `Ctrl+S` 先 `flush_virtual()`，再 `get_content()` 取整文件，写同目录临时文件后 `os.replace` 原子替换。
- 保存后大文件跳过全量 AST/lint，避免 2 MB+ 文件把 UI 卡死；问题面板提示“大文件：跳过全量诊断”。
- 徽章：`分块编辑 x-y / z 行 · 逐块自动回写（Ctrl+S 保存整文件）`，点击可转完整编辑。

实测：3,200 行 / 2.4 MB 文件，在窗口首行插入一行后保存，磁盘行数 3200 → 3201，内容包含插入标记。

## 4. 插件隔离补全

- 崩溃自动重启：`IsolatedPluginProcess.restart()` 清空事件/响应队列后重启；连续 3 次失败停止；`call_with_restart()` 失败自动重启并重试一次。
- 权限清单：插件头部 `# impor-permissions: read,write,net,process`；默认 `read=True, write=False, net=False, process=False`。
- 隔离面板宿主：`_isolated_panel()` 显示插件标题、隔离进程说明、权限清单、运行状态、重启次数、写权限，并提供「重启插件进程」。
- 文件权限：`read_file` 解析真实路径后必须落在工作区内；`write_file` / `write_current` 走 `security.safe_write` 并写审计。

边界：这是进程隔离，不是 OS 沙箱；没有 AppContainer / Job Object / 网络隔离。

## 5. UIA：可聚焦控件树 + 高对比

- `editor_uia.py` 从“朗读一段文本”升级为可操作控件树：左侧 Treeview 按 文件/编辑/运行/视图/帮助 分组列出命令（保存、打开、快速打开、命令面板、查找、跳行、重命名、提取变量/函数、运行、测试、重跑失败、覆盖率、构建 EXE、高对比/深色、编辑器/资源管理器/底部面板焦点、教学、关于）。
- 选中后 Enter 或双击 `_invoke_control()` 真正执行命令，并在右侧状态栏回显；右侧保留原生 EDIT 宿主供屏幕阅读器读取编辑区。
- 顶部「高对比主题」按钮直接 `apply_theme("hc")`。
- 边界：控件树是 Tk Treeview 的语义映射，不是逐控件 UI Automation provider；对读屏软件可用，但不具备完整 UIA 控件模式。

## 6. 索引与搜索虚拟列表

- 符号索引 `ProjectIndex.refresh(force=False)` 按 mtime 增量刷新，跳过 `SKIP_DIRS`；命令面板「重建符号索引」强制全量。
- 搜索结果虚拟列表：首次渲染 200 条，滚动到 `yview()[1] > 0.92` 自动追加下一批；状态栏显示“已显示 x / y 个文件，滚动加载更多”。
- 当前只有滚动触发加载，没有单独的「加载更多」按钮。

## 7. 安全中心

命令面板「安全中心（威胁模型 / 审计）」：

- 显示安全版本、已启用防护、信任边界、残余风险、最近 20 条审计。
- 启动时 `harden_process()` 清理 `PYTHONINSPECT` / `PYTHONSTARTUP` / `PYTHONPATH`；启动、保存、插件写入写 `.impor/audit.log`（JSONL）。
- 保存走原子写；插件写走 `safe_write` + 工作区围栏。
