# Impor (I++) v5.6 路线图与开工状态

定位：**面向中文母语的编程入门 + Windows 小工具独立 exe**。不追“语言之王”，追“学得快、发得出去、出错看得懂”。

状态口径：`已完成` = 本轮可运行并验证；`进行中` = 已有代码/文档入口，仍有明确缺口；`计划` = 只完成设计或骨架。

## A. 可信度（最高优先级）

| 项目 | 状态 | 本轮落点 | 剩余缺口 |
|---|---|---|---|
| 运行时模块完整性 | 已完成 | 桌面镜像 `impor/` 39/39，`doctor` 逐模块检查 | 发布包需持续跑 `doctor` |
| 三端语法一致 | 进行中 | `lambda` 在 C 后端给出明确“不支持”错误，不再静默 | C 后端/自举实现 lambda、interface、record、namespace |
| 修饰符语义 | 进行中 | 语法接受，文档明确“当前无访问控制语义” | 真 private/protected 访问检查，或从关键字表移除 |
| `implements` 契约 | 计划 | 语法接受接口名 | 方法存在性/签名校验 |
| 统一诊断 | 已完成 | 错误码、行列、调用栈、修复建议 | 更多错误类型补错误码 |
| 桌面同步自检 | 已完成 | 同步后跑 version/run/build 三条冒烟 | 纳入发布脚本 |
