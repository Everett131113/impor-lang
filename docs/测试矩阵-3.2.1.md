## 已知解析边界

- `match` 大括号 `case X { ... }` 在函数连续语句里可能报“期望 OP”，缩进式 `match` 稳定。
- Impor 字符串 `{...}` 会插值，JSON 字面量必须 raw string。
- C 端 lambda 为无捕获静态函数；捕获外层局部尚未支持。
