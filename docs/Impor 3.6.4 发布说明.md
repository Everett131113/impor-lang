# Impor (I++) 3.6.4 发布说明

**发布日期**：2026-11-14  
**版本**：3.6.4（编辑手感增强版）

## 本次重点

这一版不改语言语法和编译器能力，只把编辑器的输入与编辑手感补齐到日常可用水平。

## 新增与改进

- **自动配对**：输入 `(`、`[`、`{`、`"`、`'` 自动补右半边；有选区时直接包裹选中文本；光标后已有右符号时自动跳过，不再重复输入。
- **智能退格**：光标在空的 `()`、`[]`、`{}`、`""`、`''` 中间按退格，一次删掉两边，不跨行误删。
- **多行注释**：`Ctrl+/` 支持单行和选中多行；全部已注释时再次按下取消注释，保留原缩进。
- **整块缩进 / 反缩进**：选中多行后按 `Tab` / `Shift+Tab`，按设置宽度整体增减，选区保持。
- **上下移动行**：`Alt+↑` / `Alt+↓` 移动当前行；有选区时整块移动。
- **删除行**：`Ctrl+Shift+K` 删除当前行或选中行，末尾行和首行边界单独处理。
- **删词**：`Ctrl+Backspace` 删除光标前一个词；中文按连续汉字处理，英文按单词处理。
- **智能 Home**：在行首和第一个非空格之间切换，减少长缩进行里的鼠标操作。
- **缩进触发词**：`elif`、`except`、`case`、`default` 等行尾回车后自动加深一级。
- **设置开关**：设置页新增“自动配对括号与引号”，默认开启，并随项目设置保存。

## 兼容性

- 原有语法、解释器、C 后端、`imporc` 自举编译器行为不变。
- 3.6.3 的语法查询（`impor syntax`、编辑器 F1、REPL `help()`）保持不变。
- 自动配对默认开启；如使用输入法时觉得干扰，可在设置中关闭。
