## 8. 单元测试

命令：

```bat
python -X utf8 -m unittest discover -s tests -v
```

结果：**563 tests，477.6 s，9 failures，21 errors**（修复 3 个与本版直接相关的用例后）。这些失败集中在历史测试，不是本版新增功能的入口：

- `test_v29` / `test_v32` / 部分 `test_v42` / `test_v43` 仍在测 v5.2 已删除的中文关键字与软别名（`打印`、`输出`、`则`、`函数` 等），与当前「纯英文关键字」设计冲突。
- `test_v33` 的 REPL 中文块测试同样基于已删除的中文关键字。
- `test_lsp` 两个用例的临时索引根为空（`relpath` 收到空路径），属于测试夹具问题。
- `test_v42_diag` 期望调用栈包含 `b（第N行）`，当前二元运算异常栈只记录 `<main>`。
- `test_v38.test_selfhost_closure` 调用完整 `selfhost_check.py`，7.1 起该脚本未跑完（已知遗留）。

本版修复并复测：

- `test_launcher_whitelist_matches_cli`：白名单补 `dap/explain/doctor/teach/conformance/migrate-cn`。
- `test_v38.test_version_mode`：三个自举二进制版本串改为 3.1.0。
- `test_v40` 编辑器测试：适配渐进式启动，先 `open_path` 再断言标签数。

**结论**：核心新功能验证通过；全量 unittest 尚未全绿，历史用例需单独清理，不能宣称「全部测试通过」。
