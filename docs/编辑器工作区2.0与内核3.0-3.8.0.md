# 编辑器工作区 2.0 与编辑内核 3.0（3.8.0）

本版把编辑器往 IDE 的方向推进了一步，同时为“换掉 Tk Text”建立了可运行的第一阶段内核预览。两条线的完成度不同：工作区 2.0 已进入主线；内核 3.0 仍是独立预览，不替换现有 Tk 面板。

## 1 工作区 2.0

### 1.1 多根工作区

- **配置真源**：项目根 `.imporproj` 的 `roots` 列表。`load_project()` 把相对路径解析到项目 base，绝对路径保持原样；`save_project()` 在 base 内写相对路径，base 外写绝对路径。
- **入口**：
  - 资源管理器标题右侧的 `＋` / `－`；
  - 资源管理器右键菜单「添加工作区根目录…」「移除该根目录」；
  - 命令面板「添加工作区根目录」「移除选中的根目录」。
- **写回**：`_persist_workspace_roots()` 保留 `ignore`、`search_paths`、`format`，只重写 `roots`；写回后重新 `load_project()`、重建 `ProjectIndex`、刷新项目树和符号索引。
- **约束**：主根（`App.workspace`）不允许移除，提示先切换工作区；至少保留一个根。这是有意约束，避免切换工作区时把当前配置写丢。
- **标题**：显示 `工作区名 · N 根`；未信任时追加 `· 受限模式`。

### 1.2 项目树

资源管理器按 `workspace_roots` 逐个挂根节点，根内目录保持懒加载。多根时每个根是独立顶层节点，文件名冲突不合并；搜索和索引仍按真实路径去重。

### 1.3 workspace trust

- **存储**：`~/.impor_studio.json` 的 `trusted_workspaces`，元素为 `os.path.normcase(os.path.abspath(path))`。
- **判定**：`App._workspace_is_trusted()` 对当前 `workspace` 做同一规范化后查列表；`trust_current_workspace()` 写入并立即刷新横幅/状态栏。
- **受限模式**：未信任时显示横幅和「信任此工作区」按钮，状态栏显示“受限模式”。只拦截执行类操作：
  - `editor_runtime._run_task_cmd()`；
  - `editor_runtime.run_code()`；
  - `editor.build_exe()`；
  - 项目插件加载（`_finish_startup()` 中 `self.plugins and self.workspace_trusted`）。
- **不拦截**：打开/保存文件、项目树浏览、全项目搜索、编辑、格式化、语法检查等只读或本地文本操作。
- **默认策略**：`trusted_workspaces` 为空时，首次打开任何工作区都进入受限模式。用户需要点一次「信任此工作区」才启用运行/构建/终端/插件。这是当前实现，尚未改为“默认信任已有工作区”。

### 1.4 跨根搜索

`impor/editor_search.py` 的 `search_project()` 现在接受 `str` 或 `list/tuple/set`：

- 多根时逐个调用 `iter_project_files()`；
- 按 `normcase(abspath)` 去重；
- 文件必须落在任一 `roots` 的 `commonpath` 内；
- `editor_search_ui.py` 搜索线程传入 `getattr(self.app, "workspace_roots", None) or [self.app.workspace]`。

### 1.5 布局与会话恢复

`_layout_snapshot()` 保存：

- `geometry`：窗口几何；
- `paned`：左右 `paned` 的 sash；
- `center`：底部 `center` 的 sash；
- `groups`：`{"main": [abs_path...], "split": [abs_path...]}`；
- `active`：`{"main": path, "split": path}`；
- `cursor`：每个路径的光标行列；
- `scroll`：每个路径的 `yview`；
- `split_open`：分块组是否打开。

`_restore_session()` 优先按 `layout.groups` 恢复 main/split 标签；没有 `layout` 时回退旧的 `tabs`。折叠、活动标签先恢复，`after(160)` 再调用 `_restore_layout_state()` 恢复 geometry、sash、光标、滚动与 minimap。

**已知边界**：保存的是绝对 geometry，屏幕分辨率变化时可能落在屏幕外；当前未做 clamp。

## 2 编辑内核 3.0（PoC）

### 2.1 为什么是 PyQt6 QPlainTextEdit

本机环境实测：

- 可用：`PyQt6`、`PyQt6.QtWidgets`；
- 不可用：`PyQt6.QtWebEngineWidgets`、`PyQt6.QtWebEngineCore`、`PyQt6.Qsci`、`PySide6`、`PyQt5`、`pywebview`、`qscintilla`、`cefpython3`；
- WebView2 运行时存在、Edge 存在，Node 未安装。

因此第一阶段采用 **PyQt6 `QPlainTextEdit` 自绘内核**，不假装已经切到 Monaco/WebView2 或 QScintilla。

### 2.2 已实现

`impor/kernel3.py`：

- `LineNumberArea` + `CodeEditor`：行号、当前行高亮、右侧 minimap、`NoWrap`、4 空格 tab；
- `ImporHighlighter`：关键字、字符串、注释、数字；
- 多光标：`Ctrl+Alt+↑/↓`、`Alt+Shift+↑/↓` 同列加光标；主光标 + 额外光标统一插入、退格、删除、回车、Tab；`Esc` 清除；额外光标自绘竖线；
- 列编辑：当前是“同列多光标批量输入”，不是鼠标拖拽矩形选区；
- 平滑滚动：重写 `wheelEvent`，`QPropertyAnimation` 对 `verticalScrollBar().value` 做 130ms 缓动；
- 大文件：`set_plain_text_keep()` 在超过 2,000,000 字符时关闭 undo/redo；10.4MB / 100002 行无头打开约 2.3–2.8 秒；
- IME：Qt 原生处理；
- 多标签、新建/打开/保存/另存、关闭确认、未保存提示、minimap 开关、菜单与快捷键；
- `--smoke` 无头自检。

### 2.3 主编辑器入口

`impor/editor.py` 的 `launch_kernel3_preview()`：

- 检查 `PyQt6`；
- 有保存路径则传入；
- 未保存时提示并打开空白预览；
- `subprocess.Popen([sys.executable, "-m", "impor.kernel3"], cwd=INSTALL_ROOT, env=PYTHONPATH=INSTALL_ROOT)`；
- 工具栏右侧和命令面板均有入口。

**明确边界**：这是独立预览，不替换现有 Tk 面板，不宣称内核迁移完成。

### 2.4 未完成

- Monaco/WebView2 或 QScintilla 的真实接入；
- 鼠标拖拽矩形列选择；
- minimap 仅绘制缩略文本，没有视口高亮框；
- 主编辑区与 minimap/预览的滚动同步；
- LSP、调试、Git、AI、插件、项目树、主题跟随；
- 真实 IME 手测、真实滚轮手感手测、真实窗口 10MB 端到端手测；
- 保存统一写 `\n`，未保留原换行风格。

## 4 升级注意

- 首次打开未信任工作区会进入受限模式；点横幅上的「信任此工作区」后恢复运行/构建/终端/插件。
- 多根写回会直接修改 `.imporproj`；当前没有“另存为项目配置”分支。
- 布局恢复使用绝对 `geometry`，换屏幕后可能需要手动调整窗口。
- 内核 3.0 预览需要本机安装 `PyQt6`；没有时入口会提示并返回。
