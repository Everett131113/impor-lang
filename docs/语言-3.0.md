# Impor 3.0 语言与工具链

> 版本：3.0.0 · 2026-11-12
>
> 本版把「语言可信、工具链可验证」落到可运行代码：可选类型标注、返回类型检查、枚举穷尽性、`private/protected` 访问控制、增量构建、`impor conformance` 门禁与依赖审计。

## 1. 可选类型标注

变量、参数和返回值可以写类型；类型标注是可选的，不改变运行时动态语义，只在 `impor check` / 编辑器诊断中做静态检查。

```impor
var count: int = 3
var name: str = "Impor"
var ratio: float = 0.75
var maybe: int? = null

func add(a: int, b: int) -> int
    return a + b
```

规则：

- `int` / `float` 同属数值，允许双向赋值；`int` 赋 `float` 不再误报。
- `str` / `string` / `文本` 互为别名；`bool` / `boolean` 同理。
- `T?` 表示可空，`null` / `nil` / `none` 可赋给可空类型；非可空类型拒绝 `null`。
- `any` / `?` 跳过检查，用于渐进迁移。
- 返回类型与实际 `return` 值不一致报 `return-type`；变量赋错类型报 `type-mismatch`。

## 2. 枚举穷尽性

`match` 没有 `else` / `default` / 绑定通配分支时，类型检查要求覆盖枚举全部成员：

```impor
enum Color { RED, GREEN, BLUE }

func label(c)
    match c
        case Color.RED:
            return "红"
        case Color.GREEN:
            return "绿"
        case Color.BLUE:
            return "蓝"
```

少写一个成员会得到 `match-exhaustive 缺少 BLUE`。绑定模式 `case v:` 与 `_` 视为兜底，不再要求穷尽。

## 3. `private` / `protected`

访问控制同时做两层：

- 解释器运行时：外部读取 `private` / `protected` 成员抛 `AccessError`，消息为中文并带成员名。
- 同文件静态检查：`impor check` 报 `access-private` / `access-protected`，在运行前就能定位。

```impor
class Box
    private var secret: str = "hidden"
    protected var shared: int = 1

    def get_secret()
        return self.secret       // 类内允许

class Child(Box)
    def read_shared()
        return self.shared       // 子类允许 protected

var b = new Box()
// b.secret                       // AccessError / access-private
```

边界：跨文件访问控制尚未做全局分析；当前静态检查覆盖同一文件，运行时检查覆盖所有文件。

## 4. 增量构建

`impor build` 默认启用构建缓存，缓存位于 `~/.impor/build-cache.json`。缓存键包含：

- 源码 UTF-8 内容
- Impor 版本
- 输入、输出绝对路径
- TCC 的 mtime 与大小
- 被导入 `.impor` 依赖的内容

命中且输出文件 sha256 / 大小一致时，跳过转译与 TCC。强制全量：

```bat
impor build hello.impor -o hello.exe --no-cache
```

实测同一文件：首次 0.66 s，第二次 0.05 s，第三次 0.03 s（输出 100 KB，Windows + TCC）。

## 5. 一致性门禁

```bat
impor conformance            :: 跑全部用例
impor conformance --ci       :: CI 模式，失败退出非零
impor conformance --only 01  :: 只跑 01 开头用例
impor conformance --json     :: 机器可读结果
```

runner 会在运行 `imporc` 前保存 `imporc_args.txt` 原字节，结束后恢复，避免测试污染自举参数。21+ 个用例覆盖算术、字符串、数组、字典、类、继承、match、异常、闭包等。

性能门槛：

```bat
impor bench --gate
```

读取 `benchmarks/gate.json` 的 `interpreter_loop_max_ms`，超标即返回非零。

## 6. 依赖图与审计

```bat
impor pkg graph    :: 从 impor.lock 打印依赖树，标记循环与未安装
impor pkg audit    :: 缺失 lock、版本/哈希不一致、明文 HTTP 源、缺哈希、requires 缺失
```

`audit` 有「错误」退出 1，只有提示/警告退出 0，适合放进 CI。

## 7. 编辑器与教学入口

- `项目质量检查`：遍历工作区 `.impor`，聚合 lint 与类型诊断到「问题」面板，最多 300 条。
- `教学大纲（12 课）`：打开 `docs/教学大纲.md`；命令行 `impor teach` 提供可判题版本。
- 插件写 API：`write_file(path, content)` / `write_current(content)`，默认拒绝，需在 `.impor/settings.json` 的 `plugin_write_allow` 授权，路径限制在工作区。

## 8. 本版未完成（明确边界）

- 带载荷 ADT（`Option` / `Result` 的 `Some(value)` / `Ok(value)` 构造与解构）尚未实现；当前 `enum` 仍是整型常量枚举。
- `async/await` 与最小并发运行时未实现，仍为保留字。
- C 后端与自举对 JSON、正则、lambda 的覆盖未补齐；解释器可用，跨后端一致性只保证 conformance 现有用例。
- 增量缓存键未包含 `transpiler.py` / `ctrans.py` 自身内容；修改后端代码后请用 `--no-cache`。
- 跨文件访问控制、UIA 屏幕阅读器全量适配、插件独立进程隔离未完成。
