# Impor 编辑器 3.2.2：五项运行时闭环

本版只升级编辑器，语言、三端与安全策略沿用 3.2.1。五项都接真实运行路径，并保留可复现的测试证据。

## 1. 运行时行覆盖率

旧实现用“测试文件是否引用函数”做静态近似，无法回答“这一行到底跑没跑”。3.2.2 改为解释器逐语句统计。

- `impor/interpreter.py`：`Interpreter.__init__` 新增 `coverage_enabled`、`coverage`、`coverage_hits`；`_exec_stmt()` 在开关打开时按 `node.lineno` 累加；`enable_coverage(True)` 重置计数，`coverage_snapshot()` 返回 `{行号: 命中次数}`。
- `impor/editor.py`：`run_code(src=None, coverage=False)` 把覆盖开关贯通到异步 worker 与同步执行；异步 worker 完成后发 `("coverage", (path, snapshot))`，`_poll_queue` 收下并写入 `_last_coverage`。
- 视图：`_coverage_exec_lines(src)` 用 AST 语句节点行做分母；`show_coverage()` 显示“行 / 命中 / 状态 / 源码”，双击跳转；按钮“运行并统计覆盖率”“清空数据”。

实测（`_t322.json` / `_gui322.json`）：

- 可执行行 `[2,3,4,6,7,9]`，命中 8 次。
- GUI 视图 6 行，标签 `行覆盖率 100.0%（6 / 6 可执行行）· 解释器逐语句命中`。
- 首行 `["2","1","已执行","var total = 0"]`。

边界：只统计当前文件；表达式不单独计行；解释器路径有效，C 产物不产出覆盖率。

## 2. 插件面板跨进程 builder

3.2.1 的隔离进程只有一个“占位面板”，插件没法声明自己的界面。3.2.2 把 builder 放到子进程执行，父进程只收 UI 描述。

- `impor/plugin_host.py`：`_UINode` / `_UIValue` / `_UIBuilder` 记录控件类型、属性、布局与父子层级；命令注册为 `act_N`，存进 `_UIBuilder._actions`；`collect_actions()` 返回 `{id: callable}`。
- `register_panel(title, builder)` 在子进程执行 builder，异常时返回“面板构建失败”label；成功后发 `panel` 事件，载荷为 `{title, ui}`。
- `_install_tk_shim()` 在子进程 import 插件前替换 `tkinter` 常用控件为转发到 `_UINode` 的代理，旧插件 `tk.Label(frame, ...)` 写法无需改写。
- 子进程主循环与 `_request` 都处理 `op == "panel_action"`；父进程请求使用负数 id，与子进程代理请求的正数 id 分离。
- `impor/studio_ext.py`：`_isolated_panel(title, proc, ui)` 按描述递归渲染 frame / labelframe / label / button / entry / text / checkbutton / separator / tree；按钮点击调用 `proc.call_with_restart("panel_action", {"name": action})`。

实测（`_plugin322.json`）：

- `started=true`、`panel_count=1`。
- UI 三层节点：label / label / button；按钮文本“点我”。
- `actions=["act_1"]`，动作调用成功（handler 返回 `None`）。

边界：控件上限 240 个、层级上限 8 层；只支持上述控件；父进程不执行插件代码，插件仍受 3.2.1 的 audit hook 权限约束。

## 3. 索引与搜索后台化

- `impor/symbol_index.py`：`ProjectIndex` 增加 `threading.RLock()`；`refresh`、`update_text`、`symbols`、`definition`、`references`、`rename_edits`、`completion`、`stats` 全部加锁，刷新与读取不再竞争。
- `impor/editor.py`：`refresh_index_async(on_done=None, force=False)` 用 `_index_gen` 合并请求，后台线程刷新，`root.after(0, finish)` 回主线程；启动与 `open_workspace_path()` 都改走异步。
- `impor/editor_search.py`：`search_project(..., should_cancel=None)` 每处理一个文件前检查取消，已扫结果保留。
- `impor/editor_search_ui.py`：后台线程 + `_search_token` 代次 + `threading.Event`；新增“取消”“加载更多”；过期结果按 token 丢弃；取消后状态显示“已取消，保留已扫描结果”。

实测：

- `_index322.json`：4 线程并发刷新/查询 6 轮，`thread_errors=[]`，`thread_stats=[120,241,840]`；异步 `async_ready=true`、`async_files=120`。
- `_search322.json`：取消后 `busy=false`，`status="已取消，保留已扫描结果；25 个文件 / 75 处…"`，`rows=25`。
- `_search322_page.json`：首屏 200 行、总数 260；“加载更多”后 260 行，按钮转为 disabled。

边界：索引仍是项目级，跨项目符号不解析；搜索取消是协作式，正在解析的单个文件会先完成。

## 4. UIA 逐控件 provider

- `impor/editor_uia.py`：`ControlProvider` 带 `id/name/role/group/accelerator/widget/invoke/state/description`，方法 `state()`、`focusable()`、`focus()`、`invoke()`、`bounds()`、`to_dict()`。
- `build_control_providers(app)` 覆盖 editor.text、explorer.tree、problems.tree、output.text、test.tree、task.entry、memory.text、palette.input、search.dialog、run.current、run.tests、run.coverage、file.save、file.open、view.hc、a11y.bridge，共 16 个。
- `build_snapshot()` 增加 `controls`；`refresh()` 额外写 `control_providers.json`，与 `accessibility.json` 并列。
- 控件树 `columns=("role","state","accel")`、`show="tree headings"`；按 `provider.group` 分组，iid 用稳定 id；状态栏显示名称/角色/状态/快捷键；`Control+Tab` / `Shift+Tab` 循环焦点，Enter 执行。

实测（`_uia322.json` / `_gui322.json`）：

- `ok=true`，8 个分组：编辑器 / 导航 / 底部面板 / 命令 / 运行 / 文件 / 视图 / 辅助功能。
- 16 个 provider；首控件 `["文档","已保存","Ctrl+1"]`。
- 焦点状态“编辑器正文 · 角色 文档 · 状态 已保存 · Ctrl+1”。

边界：覆盖主入口，自定义插件控件尚未自动注册；provider 是应用层语义，不替代原生 UIA 控件。

## 5. 诊断 Quick Fix 扩面

- `impor/diagnostics.py`：新增 7 条规则——缺少 return、match 不穷尽、重复定义、类型不匹配、await/async、ADT 载荷数量、FFI 签名；`_ISSUE_FIX` 增加 type-mismatch、enum-nonexhaustive、duplicate-def、private-access、missing-return、async-without-await。
- `impor/editor.py`：`explain_problem()` 用 `[E\d{4}]` 提取错误码，显示标题、原文、为什么、怎么修、最小示例。
- `quick_fix_smart()`：关键字拼写（fuc / funciton / retrun / whlie / els / improt / calss / ture / fasle / nul）、未声明赋值补 `var`、条件单个 `=` 改 `==`、括号/方括号/大括号补齐、单双引号补齐、未使用变量删除。
- `quick_fix_all()`：不可达语句删除、文件末尾未闭合大括号补齐；前后 `edit_separator()`，提示可按 `Ctrl+Z` 撤销。

实测（`_fix322.json`）：

- `fuc add(a, b) {` 修复为 `func add(a, b) {`。
- 解释窗口包含“原文 / 为什么 / 怎么修 / 最小示例”，正文含 `NameError: 名字 nope 未定义`。

边界：修复仍以单行/局部为主，复杂控制流需人工确认；一次 `Ctrl+Z` 只撤一个修复单元。
