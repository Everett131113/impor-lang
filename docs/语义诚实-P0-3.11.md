# 语义诚实 P0（3.11 修订）

> 目标不是“功能更多”，而是“说到做到”：凡是没实现的写法，必须在语法阶段明确报错，
> 而不是 rc=0 静默变成另一种行为。

## 1 两个实测 bug 的根因与修复

| 写法（修复前） | 修复前行为 | 根因 | 修复后 |
|---|---|---|---|
| `async def f()` | rc=0，函数按同步执行 | `async` 是软关键字，parser 只设 `is_async`，解释器未消费 | `impor run` 语法错误，rc=2 |
| `defer print("d")` | 立刻打印 `d`，rc=0 | `defer` 只在代码块写法转成 `Defer`，`defer expr` 退化为普通调用 | `impor run` 语法错误，rc=2；`defer { ... }` 保持可用 |
| `print(await g())` | rc=0，按同步调用 | `Await` 节点无调度器语义 | 语法错误，rc=2 |
| `const x = 5; x = 6` | rc=0，输出 6 | 快速转译路径绕过 `visit_Assign` 的 `ConstError` | `impor run`：`ConstError`，rc=1；`impor build`：构建期拒绝 |

修复点：

- `impor/lexer.py`：新增 `UNIMPLEMENTED_SOFT_KEYWORDS`、
  `UNIMPLEMENTED_RESERVED_KEYWORDS`、`UNIMPLEMENTED_KEYWORDS` 三个分类集合。
- `impor/parser.py`：语句位置统一拦截；`await` 接操作数时拒绝；
  `static/readonly` 只在变量声明位置保留，方法/类修饰位置拒绝。
- `impor/interpreter.py`：`_fast_eligible()` 遇到 `Assign(scope="const")` 直接回退树遍历，
  由 `visit_Assign` 兑现只读检查。
- `impor/ctrans.py`：新增 `_reject_const_mutation()` 预扫描；C 后端不跟踪 const 环境，
  对 const 名字的 `Assign` / `CompoundAssign` 在构建期拒绝，只读 const 仍正常出 exe。
- 错误文案统一为「xxx 尚未实现（v3.x 计划）；不再静默接受或执行」。

## 2 6 个软关键字的真实分类（更正）

源码核查后，6 个软关键字不是同一种状态，不能一律拒绝：

| 关键字 | 真实状态 | 处理 |
|---|---|---|
| `async` | 静默丢失 | 明确拒绝，exit 2 |
| `await` | 静默同步执行 | 明确拒绝，exit 2 |
| `defer` | 非代码块写法静默退化成普通调用 | `defer { ... }` 已实现保留；`defer expr` 明确拒绝，exit 2 |
| `static x = 1` | const 别名，改值会报 `ConstError` | 保留为已实现，纳入兑现表 |
| `readonly x = 1` | const 别名，改值会报 `ConstError` | 保留为已实现，纳入兑现表 |
| `this.x` | 类方法内映射到 `self.x` | 保留为已实现，纳入兑现表 |

因此“6 个各一条 exit 2 测试”按字面无法同时成立：3 个是真静默坑，另外 3 个已经能用。
把它们也拒绝会造成功能倒退，反而制造新的“说假话”。本修订选择：
**能用的保留并测试，不能用的拒绝并测试。**

`public/private/protected` 同样不是空占位：parser 写入 `visibility`，
interpreter 在类成员和跨文件导入时抛 `AccessError`，因此保留。

## 3 保留字兑现表

新增 `tools/keyword_audit.py`，遍历 `KEYWORDS + SOFT_KEYWORDS + final`，输出三张表：

- 已实现（53）
- 明确拒绝（12）：`abstract / async / await / defer / final / implements /
  interface / namespace / override / sealed / with / yield`
- 静默接受（0）

每个“明确拒绝”项都有语句级探针，必须真实抛 `ImporSyntaxError` 且文案含「尚未实现」；
静默接受非空即 exit 1。完整 65 项公开表见
[保留字兑现表.md](保留字兑现表.md)（由脚本生成，不手改）。

已接入 `.github/workflows/ci.yml`：

```bash
python tools/keyword_audit.py
```

## 4 验收

```bash
python tools/keyword_audit.py
python -m unittest tests.test_semantic_honesty -v
python run_tests.py
```

`tests/test_semantic_honesty.py` 覆盖：

- `async def` / `defer` / `await expr` 各 1 条 CLI 断言 rc=2；
- `interface` / `abstract` 占位保留字 rc=2；
- `const` / `static` / `readonly` 改值 rc=1 且含 `ConstError`；
- `const` 读取正常；`this.x` 类内取值正常；
- `const` 改值的 C 后端构建被拒绝，且不产出 exe。
