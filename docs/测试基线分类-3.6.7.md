## 3.6.14 移出自举闭包

`test_v38.TestImporcSelfHost.test_selfhost_closure` 原在 `LEGACY_IDS`，原因是旧 `imporc.exe` 编译 86KB 新种子超过 300 秒超时。3.6.14 用 Python C 后端重建 A，并修 `rt_strcut` 的 O(n²)，完整种子编译降到 52.56 秒，`A→B→C→D` 闭环 B/C/D 逐字节一致。

- `LEGACY_IDS`：6 → 5；
- 默认 suite 实际执行该用例：**567 tests / OK**；
- 全量 `--all`：572 tests，剩余 5 条旧语法/功能口径项。
