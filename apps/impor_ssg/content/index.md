# Impor 文档站（由 Impor 生成）

这是 `apps/impor_ssg` 生成出来的站点：读 `content/*.md`，套 `templates/layout.html`，
写 `_site/*.html`。生成器本身用 Impor 写，不依赖 Python、Node 或第三方包。

## 三分钟

1. 解压 → 双击 `开始这里.bat` → 看到「你好，Impor」。
2. 双击 `1-你好.bat` / `2-读文件.bat` / `3-调DLL.bat`。
3. 卡住看 `常见问题.txt`。

## 为什么值得试

- 单文件 exe 约 121.5 KB，脱离 Python 运行。
- 报错带位置、人话原因、修法、稳定错误码和文档锚点。
- 3.12–3.14 不删已发布 API；改动必须走 RFC。
